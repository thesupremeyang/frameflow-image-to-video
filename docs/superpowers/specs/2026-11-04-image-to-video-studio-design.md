# 帧流 FrameFlow 设计说明

日期：2026-11-04

## 目标

提供一个本地网页工作台，将用户上传的首帧图片和生成提示词提交给官方视频模型，支持 Seedance 2.5、Seedance 2.0 与 MiniMax H3，并统一呈现任务状态、视频预览和下载。

## 架构

采用 FastAPI、原生 HTML/CSS/JavaScript、SQLite 与 boto3，不需要前端构建链。默认仅监听 `127.0.0.1`。模型密钥、接口地址、模型 ID 和 S3 参数直接在页面的“模型配置”弹窗中填写，持久化到本地 `data/settings.json` 并立即更新运行时配置，不需要编辑文件或重启。保存时进行 HTTPS 地址、字段长度和控制字符校验，只允许本地来源修改配置。API 只返回配置状态和公开字段，绝不回显已保存的密钥。环境变量仍作为高级部署时的默认值。

前端为单页工作台：左侧设置图片、提示词、模型、时长、清晰度和音频，右侧显示结果，底部为最近创作。模型参数随能力配置联动，图生视频使用自适应比例。

`providers` 适配器隔离官方接口差异。Seedance 直接提交 Base64 data URI；MiniMax 将本地图片上传至用户配置的 S3 兼容公开存储，再提交 HTTPS URL。`TaskManager` 持久化云端任务 ID，异步轮询并将视频下载到本地，启动时恢复未完成任务。

## 接口

- `GET /api/config`：模型能力与密钥是否已配置，不返回密钥。
- `POST /api/generations`：multipart 图片及生成参数，返回本地任务。
- `GET /api/generations`：最近任务。
- `GET /api/generations/{id}`：任务状态。
- `GET /api/generations/{id}/image`：本地首帧。
- `GET /api/generations/{id}/video`：已下载的视频。
- `GET /api/generations/{id}/download`：下载视频，必要时从已验证的云端地址重试。
- `DELETE /api/generations`：确认后清空本地任务和文件，不影响云端任务。

## 安全和失败处理

服务端检查真实图片格式、30 MB 限制、尺寸、宽高比和模型参数。下载只接受已配置的云厂商 HTTPS 域名，不跟随重定向，拒绝私网地址，限制下载体积和超时。

不自动重复创建云端任务，避免无幂等键的网络重试造成重复生成和扣费。网络查询失败最多重试三次。缺少密钥、S3 配置或权限时显示可操作的错误，不伪装成功。清空本地记录有明确确认，且不声称会删除云端素材。

## 验证

通过 `httpx.MockTransport` 验证三个模型的请求结构、鉴权、轮询和失败映射。通过 FastAPI 测试客户端与模拟 provider 验证生成流程、S3 调用、下载、历史、清理和恢复，不产生真实云端费用。浏览器验证桌面与窄屏布局、模型参数联动、表单错误和任务展示。
